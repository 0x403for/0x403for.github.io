Langkah Validasi Masalah (Sesuai Hasil Pengujian):
  1. Akses halaman ini melalui browser Firefox atau Safari di perangkat iOS.
  2. Ketuk salah satu tombol pemicu di atas untuk mengarahkan navigasi ke string URL hasil mutasi.
  3. Sistem keamanan anti-phishing iOS akan mencegat URL dan menampilkan layar peringatan merah pada objek about:blank.
  4. Indikator Malfungsi: Perhatikan bilah navigasi bawah browser. Tombol panah kiri (Back) dan kanan (Forward) akan terkunci dan berubah warna menjadi abu-abu (disabled), menandakan rusaknya sinkronisasi status riwayat navigasi (*history stack*).
