⚠️ URL Formatter Crash Test

PoC ini menyuapkan payload hasil mutasi fuzzer langsung ke mekanisme navigasi browser untuk menguji ketahanan komponen parser C++.

Cara Pengujian & Pembuktian:
  1. Pastikan fitur log crash aktif di browser target.
  2. Klik tombol merah di atas. JavaScript akan membuka tab/jendela baru menggunakan payload tersebut secara utuh.
  3. Indikator Rentan: Jika tab yang baru terbuka mendadak mati (Aw, Snap! / Crash), seluruh browser menutup paksa, atau muncul log pelanggaran memori pada ASAN/Debugger.
  4. Setelah itu, buka tab baru dan ketik chrome://crashes untuk melihat laporan bukti Crash ID resminya.
