Browser Polyglot Behavior Test Suite

Apa yang diuji: Bagaimana browser modern (Chrome, Firefox, Edge, Safari) menangani file polyglot ketika disajikan melalui berbagai cara — inline data: URI, blob: URL, iframe srcdoc, dan download + buka manual. Fokus pada MIME sniffing, parsing ambiguity, dan Content-Type enforcement.

1. Data URI — MIME Sniffing Test

Browser dulu bisa sniff konten data URI dan mengabaikan Content-Type yang diset. Apakah browser modern masih melakukannya?
Ekspektasi: Browser modern tidak akan menjalankan script jika MIME tidak sesuai.
CSV sebagai text/csv harus aman
CSV sebagai text/html bisa XSS
CSV sebagai application/octet-stream harus download

2. Blob URL — Forced Content-Type

blob: URL yang dibuat via JavaScript memungkinkan kita set MIME secara eksplisit. Apakah browser menghormatinya?
Blob text/csv harus aman
Blob text/html XSS jika di-render
Blob tanpa MIME (kosong) sniffing test

3. Simulasi Upload — Download + Render

Mensimulasikan skenario: user upload file polyglot, server menyimpannya, lalu menampilkannya kembali. Download file lalu buka di browser — apakah XSS tereksekusi?

4. iframe srcdoc — Parser Boundary Test

srcdoc selalu di-render sebagai HTML, tidak peduli kontennya. Sementara src dengan data URI mengikuti aturan MIME.
srcdoc dengan konten CSV XSS
src=data:text/csv... harus aman

5. PDF/HTML Polyglot — PDF Parser Boundary

File yang diawali magic bytes PDF (%PDF-1.4) tapi juga mengandung HTML di dalamnya. Test apakah browser memprioritaskan PDF parser atau HTML parser saat file dibuka langsung.
Buka file hasil download — lihat apakah browser render sebagai PDF atau HTML
