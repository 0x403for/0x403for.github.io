Picu via Link (<a> tag)
Cara Eksekusi & Analisis di iPhone:
  1. Host file HTML ini di server lokal (misal memakai python3 -m http.server di WSL kamu) atau upload ke GitHub Pages agar bisa diakses dari iPhone.
  2. Buka link tersebut menggunakan aplikasi Firefox di iOS.
  3. Coba klik tombol merah, atau klik langsung tautan "Picu via Link".
  4. Tanda Kerentanan (Crash): Jika aplikasi Firefox mendadak tertutup total kembali ke Home Screen (*springboard*), atau tab membeku (*freeze*) secara permanen.
