URL Fixup Security Tester

Klik link di bawah ini untuk melihat apakah Address Bar tertipu atau melakukan normalisasi yang tepat.

1. Test Kasus Host (Baris 703+)

  • Test ..www.example.com
  • Test www.example.com..
  • Test .www.example.com.
  • Test www.example

2. Test Skema dan Delimiter

  • Test http;www.google.com/

Perhatikan: Jika browser melakukan "Fixup", browser akan mengarahkan Anda ke URL yang benar. Jika Address Bar menampilkan domain yang Anda klik (misal: example.com) namun isinya berbeda, itu adalah temuan krusial.
