1inch dApp Browser Scanner PoC

Alat uji mandiri untuk memetakan objek jembatan dan eksposur API di dalam peramban dApp.

Petunjuk Penggunaan:

  1. Unggah kode ini ke server hosting uji coba Anda (atau gunakan file lokal yang dapat diakses).
  2. Buka tautannya melalui peramban dApp di dalam aplikasi 1inch Wallet.
  3. Lihat hasil pemindaian pada layar untuk mendeteksi objek *bridge* yang aktif di lingkungan peramban tersebut.
