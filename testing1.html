Coin98 dApp Browser Scanner PoC

Alat uji mandiri untuk memetakan objek jembatan dan eksposur API di dalam peramban dApp Coin98 Wallet.

Petunjuk Penggunaan:

  1. Unggah kode ini ke server hosting pengujian Anda (mendukung HTTPS).
  2. Buka tautannya melalui peramban dApp di dalam aplikasi Coin98 Wallet.
  3. Lihat hasil pemindaian pada layar untuk mendeteksi objek *bridge* atau injeksi provider yang aktif di peramban tersebut.
