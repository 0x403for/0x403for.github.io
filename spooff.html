Firefox iOS Bug PoC: Address Bar Spoofing

Klik tombol di bawah untuk menguji spoofing address bar menggunakan firefox://open-url scheme.

Cara Kerja:

1. Bug ini menggunakan skema URL firefox://open-url

2. Parameter javascript://google.com/... membuat address bar

3. Tapi konten di-render dari skrip JavaScript, bukan dari google.com

Catatan: Bug ini sudah dilaporkan dan sebagian sudah diperbaiki
