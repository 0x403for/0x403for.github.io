Cara ngetes Add to Home Screen:

  1. Di Firefox iOS, pencet tombol Share (kotak + panah ke atas) di bawah.
  2. Pilih Add to Home Screen / Tambah ke Layar Utama.
  3. Liat preview-nya: Nama-nya apa? Icon-nya apa?
  4. Kalau preview-nya nunjukin Nama "BCA Mobile" + Icon logo BCA, berarti Firefox ngizinin website palsuin nama + icon jadi bank.
  5. JANGAN pencet Add / Tambah beneran kalau lu gak mau icon palsu nempel di Home Screen lu. Cuma liat preview-nya aja, terus Cancel.
  6. Kalau lu terlanjur pencet Add, hapus icon-nya dari Home Screen (tekan lama -> Hapus).
